## App Review Notes (Apple)

```
OTP Buddy is a macOS menu-bar (agent) app. There is no Dock icon by default (LSUIElement). Opening the main window temporarily shows a Dock icon (menu-bar pin otherwise).

NO LOGIN / DEMO ACCOUNT REQUIRED beyond the user’s own IMAP credentials (stored in Keychain).

Launch at login: OFF by default. On first launch the app opens the main window and shows a consent popup (Not Now / Open at Login).
It only registers as a Login Item if the user chooses Open at Login. Later launches stay menu-bar only (Guideline 2.4.5(iii)).

How to review:
1. Launch the app. Look for the OTP icon in the macOS menu bar.
2. Open Settings and enter IMAP host/credentials (or use Demo: ingest sample OTP email).
3. Confirm codes appear in the menu bar; optional auto-copy is off by default.

Privacy:
- App connects to user-provided IMAP host with user credentials (Keychain).
- Reads recent inbox messages locally to detect verification codes.
- Does not send email contents to our servers.
```

Shared lanes live in `Vendor/shared-buddy/scripts/store/Fastfile` (or sibling `../shared-buddy`). Metadata is generated by `prepare_deliver_metadata.py` (do not edit `fastlane/metadata` or `fastlane/screenshots` by hand).

## Lanes

| Lane | What it does |
|------|----------------|
| `bundle exec fastlane mac prepare` | Build `fastlane/metadata` + `fastlane/screenshots` from `STORE.md` and banner PNGs |
| `bundle exec fastlane mac build` | Archive + export signed Mac App Store `.pkg` into `build/` |
| `bundle exec fastlane mac beta` | Build + upload `.pkg` to TestFlight |
| `bundle exec fastlane mac metadata` | Upload listing copy + screenshots (no binary) |
| `bundle exec fastlane mac screenshots` | Upload screenshots only |
| `bundle exec fastlane mac release` | Build + upload binary, metadata, and screenshots |
| `bundle exec fastlane mac release submit:true` | Same as release, then submit for App Review |
